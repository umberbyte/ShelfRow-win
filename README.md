# ShelfRow for Windows

**ShelfRow for Windows** は、macOS / iPadOS 版「**ShelfRow**」の設計思想（かつて愛された蔵書管理アプリ「Stackroom」のコンセプト・軽快性・資産を継承し、NAS運用を前提とした書庫管理）をそのまま Windows ネイティブ環境向けに提供するアプリケーションです。

動作が遅くなりやすい電子書籍・コミック管理において、徹底した軽量・高速性を追求し、数万冊規模のライブラリでも軽快に動作する設計を行っています。

> [!IMPORTANT]
> iCloud同期を利用するには、iCloudを利用できるApple Account（Apple ID）が必要です。同期機能は、Mac版ShelfRowとWindows版ShelfRowを併用する環境を前提にしています。
>
> iCloud同期を有効にしなければ、Apple AccountやMacがなくてもWindows単体の蔵書管理アプリとして利用できます。蔵書、シェルフ、設定はWindows内のローカルデータベースに保存されます。

---

## 🌟 主な特徴

- **iCloud (CloudKit) 双方向同期**:
  - macOS版およびiPad版（SwiftData / CoreData CloudKit Mirroring）と完全に同一の `iCloud.com.eureka.ShelfRow` コンテナ、`com.apple.coredata.cloudkit.zone` と同期。
  - Apple公式の **CloudKit Web Services REST API** を利用し、Windows環境からセキュアに蔵書メタデータを双方向同期します。
- **NAS運用に特化したボリューム管理**:
  - 書籍ファイルの実体はNASに配置。
  - macOSのPOSIXパス（`/Volumes/Books/...`）と WindowsのUNCパス（`\\NAS\Books\...`）またはドライブ文字（`Z:\...`）の自動相互変換・マッピング。
- **サムネイルのNAS分散キャッシュ共有**:
  - 著作権保護および容量（ギガバイト単位）の観点から、サムネイル画像はiCloudを経由せず、NAS上の共有フォルダ（`ShelfRowThumbnails`）を介してMac・iPad・Windows間で配布・同期します。
- **Stackroom からの資産移行**:
  - `Stackroom Library.xml` のストリーミングインポートに対応。不正な制御文字を自動除去して安全にインポート。
  - 書籍情報、フォルダ／本棚、スマート本棚条件、評価（レート）、未読状態を完全再現。
- **Windows ネイティブ & 高速仮想化UI**:
  - C# / .NET 10 + WinUI 3 (Windows App SDK) による Fluent Design。
  - UI仮想化技術により、大量の書影（サムネイル）を省メモリかつ滑らかにスクロール表示。

## 利用形態

ShelfRow for Windowsは、次の2通りで利用できます。

### MacとiCloud同期して使う

Mac版ShelfRowとWindows版ShelfRowで、蔵書の書誌情報、シェルフ、ボリューム情報を共有する使い方です。Apple AccountでCloudKitへサインインする必要があります。書籍ファイルと表紙画像はiCloudへ送信されないため、必要に応じてNASと`ShelfRowThumbnails`共有フォルダーも用意します。

初めて同期を有効にする端末では、残す蔵書を必ず選択します。

- **この端末の蔵書をiCloudへ送る（1台目）**: Windows側の蔵書を同期元にします。
- **iCloudの蔵書で置き換える（2台目以降）**: Windows側の蔵書とボリュームのパスマッピングを消去し、iCloud側の蔵書を受信します。書籍の実体ファイルは削除されません。

2つの蔵書を自動的に突き合わせて統合する機能ではありません。選択前に自動バックアップが作成されますが、どちらを同期元にするか確認してから有効にしてください。

### Windows単体で使う

iCloud同期をオフのまま使用します。Apple Account、Mac、CloudKitの設定は不要です。`Stackroom Library.xml`をインポートし、蔵書の検索、編集、シェルフ整理、外部ビューアでの閲覧、表紙管理、バックアップをWindowsだけで利用できます。NASを使わず、Windowsから参照できるローカルフォルダーやドライブに書籍ファイルを置くこともできます。

## インストールと初回起動

1. PCのCPUに合うセットアップを実行します。
   - 一般的なIntel/AMD搭載PC: `ShelfRow-<version>-win-x64-Setup.exe`
   - Windows on Arm PC: `ShelfRow-<version>-win-arm64-Setup.exe`
2. セットアップ画面に従ってインストールし、スタートメニューの「ShelfRow」を起動します。
3. 既存データを用意します。
   - Stackroomから移行する場合は、**設定 > 保守 > Stackroom XMLライブラリのインポート**を使います。
   - Mac版ShelfRowの蔵書を受信する場合は、**設定 > iCloud**で同期を有効にし、「iCloudの蔵書で置き換える（2台目以降）」を選びます。
4. NASや別ドライブ上の書籍を開く場合は、**設定 > 保守 > ボリューム管理**でWindows側のパスを割り当てます。
5. ZIPなどのアーカイブや画像フォルダーを読む外部アプリを、**設定 > ビューア**または**設定 > ヘルパー**で指定します。CBZなどZIP以外の拡張子は**設定 > ヘルパー**で個別に割り当てます。

Private Trustで署名したセットアップを使う場合は、その署名用ルート証明書を信頼済みの端末へ先に配布する必要があります。詳細は[配布先向け説明書](installer/README-ja.txt)を参照してください。

## メイン画面の使い方

メイン画面は、左のライブラリ、中央の蔵書一覧、右の詳細インスペクターで構成されています。

### 蔵書を表示する

- **すべての項目**を選ぶと蔵書全体を表示します。
- **未読**を選ぶと未読の本だけを表示します。
- **お気に入り**の標準シェルフ、または**スマートシェルフ**を選ぶと、そのシェルフに含まれる本を表示します。
- 上部の**リスト／グリッド**で表示形式を切り替えます。
- 並び替えメニューではタイトル、レート、作者、登録日、ページ数を選び、矢印ボタンで昇順と降順を切り替えます。リスト表示では各列の見出しからも並び替えられます。
- リストの見出し部分を右クリックすると、表示する列を選べます。列見出しはドラッグして並べ替えられます。

### 検索と絞り込み

- 上部の検索欄へ文字を入力すると、表示中の蔵書を検索します。
- **未読**、6種類の種別、★1～★5の評価を組み合わせて絞り込めます。同じボタンをもう一度押すと解除できます。
- **フィルタをクリア**ですべての絞り込みを解除します。
- 右側の詳細にある作者、ジャンル、関連、キーワードの検索ボタンを押すと、その値を使って蔵書全体を検索します。
- **設定 > キーワード**で同一視グループを作ると、表記違いの作者名やジャンルなどを同じ語として検索できます。

### 書誌情報を表示・編集する

中央の本を選択すると、右側に表紙と書誌情報が表示されます。タイトル、作者、評価、キーワードA/B、メモ、ジャンル、関連、未読状態を直接編集できます。変更は自動保存され、iCloud同期が有効なら同期対象になります。

よく入力する文字列は**スタンプ**として登録できます。入力先の欄を選び、スタンプを押して入力します。**編集**を押すと、1行につき1項目の形式でスタンプを追加・変更できます。

### 本を開く

本をダブルクリックするか、選択して`Enter`キーを押します。右クリックメニューの**開く**も利用できます。ShelfRow自身は書籍ビューアを内蔵していないため、設定した外部アプリまたはWindowsの既定アプリで開きます。正常に開いた本は既読になり、最終閲覧日が更新されます。

右クリックメニューから、未読状態、レート、種類、標準シェルフへの所属も変更できます。**ライブラリから削除**はShelfRowの登録だけを削除し、書籍の実体ファイルは削除しません。

## シェルフの使い方

### 標準シェルフ

1. 左下の追加メニューから**新規標準シェルフ**を選び、名前を入力します。
2. 本を右クリックし、**標準シェルフ**のサブメニューで所属先をオンまたはオフにします。
3. シェルフを右クリックすると、名前の変更または削除ができます。シェルフを削除しても本や実体ファイルは削除されません。

### スマートシェルフ

左下の追加メニューから**新規スマートシェルフ**を選びます。タイトル、作者、ジャンル、関連、キーワードA/B、メモの文字条件、種別、評価、未読、登録日または最終閲覧日の条件を組み合わせられます。文字条件は「含む」「含まない」「一致」、日付条件は「指定日数以内」「指定日数より前」から選びます。条件に合う本は自動的に表示されます。

スマートシェルフを右クリックすると、条件の編集または削除ができます。

## Stackroom XMLをインポートする

1. **設定 > 保守 > Stackroom XMLライブラリのインポート**を押します。
2. `Stackroom Library.xml`を選択します。
3. 解析と保存が終わるまで待ち、完了画面で書籍数とシェルフ数を確認します。
4. **ボリューム管理**を開き、各macOSパスへ対応するWindowsパスを設定します。

インポートは大きなXMLをストリーミング処理し、XML 1.0で使用できない制御文字を除去します。同じライブラリを再インポートした場合は既存データと照合し、書籍やシェルフの重複登録を避けます。

## ボリュームと書籍ファイルの設定

Mac側で記録された`/Volumes/Books`などのパスを、Windowsでアクセスできる`\\NAS\Books`や`Z:\Books`へ割り当てます。

1. **設定 > 保守 > ボリューム管理**を開きます。
2. 対象ボリュームの**Windowsパス**へUNCパスまたはドライブ上のフォルダーを入力します。**参照**で選択することもできます。
3. macOSパスから候補を作れる場合は**自動推定**を利用します。
4. **保存して閉じる**を押します。

書籍を開けない場合は、ボリュームが接続済みか、割り当て先に実体ファイルがあるかを確認してください。

---

## 外部ビューアとヘルパーの設定

- **設定 > ビューア > スライドショーヘルパー**: 画像フォルダーを開くアプリを指定します。
- **設定 > ビューア > Zip アーカイブヘルパー**: `.zip`ファイルを開くアプリを指定します。
- **設定 > ヘルパー**: 拡張子とアプリの組み合わせを追加します。複数の拡張子はコンマ区切りで入力できます。

個別の拡張子にヘルパーが設定されていないファイルは、Windowsの既定アプリで開きます。ヘルパーには`.exe`、`.bat`、`.cmd`を指定できます。

## 表紙とサムネイルを管理する

- 表紙がないZIP/CBZでは、アーカイブ内の先頭画像から表紙を自動生成します。
- 別の画像を使う場合は本を選び、右側の**表紙を編集**を押します。スライダーでアーカイブ内の画像を確認し、**この画像を表紙にする**を押します。
- Mac、iPad、Windowsで表紙を共有する場合は、NAS上に`ShelfRowThumbnails`フォルダーを用意し、**設定 > 保守 > サムネイルの配布**でそのフォルダーを指定します。
- **配布元からサムネイルを一括取得**、または**ボリューム管理 > サムネイルを一括同期**で未取得・更新済みの表紙をローカルへ取り込みます。

サムネイル画像はiCloudへ送信されません。NASが一時的に利用できない場合、Windowsで変更した表紙は保留され、共有フォルダーへ接続できた時に配布されます。

## iCloud同期を設定する

同期には、iCloudを利用できるApple Accountとインターネット接続が必要です。この機能はMac版ShelfRowとの混在環境向けです。Windows単体で使う場合は、この設定を行わず同期をオフのままにしてください。

1. **設定 > iCloud**を開きます。
2. 通常は環境を**Production**のままにします。
3. **サインイン**を押し、表示されたAppleの画面でサインインします。
4. **iCloud同期**をオンにします。
5. 最初の同期元にするWindows端末では**この端末の蔵書をiCloudへ送る（1台目）**、既存のMac版ShelfRowの蔵書を受け取るWindows端末では**iCloudの蔵書で置き換える（2台目以降）**を選びます。

同期が有効な間は、書誌情報、シェルフ、ボリュームの変更がCloudKitと双方向同期されます。**今すぐ同期**を押すと、ローカル変更の送信後にiCloud側の増分変更を受信します。

書籍ファイルとサムネイル画像はiCloud同期の対象外です。書籍ファイルはNASなど同じ保管先を各端末から参照し、サムネイルは`ShelfRowThumbnails`で共有してください。

通常の利用では組み込みのProduction用APIトークンを使うため、**APIトークン**欄は空のままで構いません。別のCloudKitコンテナを使う場合だけ、専用のAPIトークンとコールバックURL設定が必要です。

**全件をiCloudへ再送信**と**iCloudのデータを完全に削除**は、1台目として設定した端末だけで使える保守操作です。特に完全削除は取り消せないため、他の端末の同期を停止し、バックアップを確認してから実行してください。

## 設定画面

設定は変更時に保存されます。

- **一般**: ライト／ダーク表示、列の並び順と幅を全体またはシェルフごとに保存する設定、コンパクト表示、メインウインドウを閉じた時の終了動作を変更します。
- **ビューア**: 画像フォルダーとZIPアーカイブを開く外部アプリを設定します。
- **ヘルパー**: 拡張子ごとに起動する外部アプリを設定します。
- **キーワード**: 作者、ジャンル、関連、キーワードA/B、メモに対する同一視グループを作ります。
- **カスタマイズ**: 6種類の種別名と、作者、ジャンル、関連、キーワードA/Bの表示名を変更します。
- **iCloud**: サインイン、同期の有効化、手動同期、同期データの保守を行います。
- **セキュリティ**: 起動時の簡易ロックとパスワードを設定します。
- **保守**: バックアップ、サムネイル配布、ボリューム管理、Stackroom XMLインポートを行います。

簡易ロックはShelfRowの画面表示を保護する機能です。Windowsアカウントやデータベース自体を暗号化する機能ではありません。

## バックアップとリストア

1. **設定 > 保守 > バックアップ**を有効にします。
2. **選択**でバックアップ先フォルダーを指定します。
3. **今すぐバックアップ**を押します。指定先の`ShelfRowBackup`フォルダーへ、データベース、ローカルサムネイル、設定ファイルが差分コピーされます。

復元する場合は、同じ画面でバックアップ先を指定して**バックアップからリストア**を押します。復元データは検証後に準備され、ShelfRowを次に起動した時に適用されます。

## 🏛 アーキテクチャ構成

クロスプラットフォーム検証が容易なように、コアロジックをUIから完全に分離した疎結合なマルチプロジェクト構成を採用しています。

```
ShelfRow for Windows/
├── src/
│   ├── ShelfRow.Core/       # ドメインモデル (Item, Shelf, Volume) および抽象インターフェース
│   ├── ShelfRow.Data/       # 高速SQLiteリポジトリ (ローカルキャッシュ・検索・インデックス)
│   ├── ShelfRow.CloudKit/   # Apple CloudKit Web Services クライアント & 差分同期エンジン
│   ├── ShelfRow.Importer/   # Stackroom XML (Apple plist) ストリーミングパーサー
│   ├── ShelfRow.Storage/    # NASボリュームパス変換 & サムネイル共有マネージャー
│   └── ShelfRow.App/        # WinUI 3 (Windows App SDK) デスクトップアプリケーション
└── tests/
    ├── ShelfRow.Core.Tests/
    ├── ShelfRow.Data.Tests/
    ├── ShelfRow.CloudKit.Tests/
    ├── ShelfRow.Importer.Tests/
    └── ShelfRow.Storage.Tests/
```

> [!NOTE]
> `ShelfRow.Core`、`ShelfRow.Data`、`ShelfRow.CloudKit`、`ShelfRow.Importer`、`ShelfRow.Storage` およびテスト群は、プラットフォーム非依存の純粋な .NET 10 ライブラリです。macOS環境上でも全単体テストを即座にビルド・実行（`dotnet test`）できます。

## 配布用インストーラー

Windows 上で .NET 10 SDK と Inno Setup 6 を用意し、次を実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1 -Version 1.0.0
```

必要に応じて `-IsccPath 'C:\path\to\ISCC.exe'` を指定します。
出力は `artifacts\installer\dist\ShelfRow-1.0.0-win-x64-Setup.exe` と `ShelfRow-1.0.0-win-arm64-Setup.exe` です。
SHA-256 と配布先向けの説明書も同じフォルダーに生成します。
スクリプトは Microsoft 署名を検証した依存ランタイムを使用します。
署名オプションを省略した生成物は未署名です。署名して配布する場合はコード署名証明書を別途用意してください。

Azure Artifact Signing を使う場合は、署名アカウントへログインできる環境で次を実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1 `
  -Version 1.0.0 `
  -SigningEndpoint 'https://jpe.codesigning.azure.net' `
  -SigningAccountName '<account-name>' `
  -CertificateProfileName '<profile-name>' `
  -SigningProfileType PublicTrust
```

署名を指定すると ShelfRow の EXE/DLL、セットアップ、アンインストーラーを SHA-256 と Microsoft のタイムスタンプで署名し、検証後に SHA-256 ファイルを生成します。
Private Trustを指定した場合は説明書を出力します。`-PrivateTrustRootCertificatePath` にMicrosoft公式コマンドで取得したルート証明書を渡すと、整合性ハッシュとともに配布フォルダーへコピーします。Private TrustはWindowsで既定には信頼されないため、一般公開にはPublic Trustを使用してください。

対応環境・インストール方法は [配布先向け説明書](installer/README-ja.txt) を参照してください。
