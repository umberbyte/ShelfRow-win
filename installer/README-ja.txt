ShelfRow for Windows - インストール手順

対象: Windows 10 バージョン 2004 (build 19041) 以降 / Windows 11

ファイル名の win-x64 は Intel/AMD 64-bit PC 用、win-arm64 は ARM64 PC 用です。

1. ShelfRow-<バージョン>-win-x64-Setup.exe を実行します。
2. 管理者権限を許可し、ウィザードに従ってインストールします。
3. スタートメニューの ShelfRow から起動します。

.NET と Windows App SDK は同梱済みです。
Visual C++ x64 ランタイムは必要な場合に同梱インストーラーから導入します。
WebView2 が未導入の場合は Microsoft からダウンロードするため、インターネット接続が必要です。
iCloud 認証と NAS パスはアプリ内で設定してください。

更新時は ShelfRow を終了し、新しいセットアップを実行してください。
アンインストールは Windows の「インストールされているアプリ」から行います。
蔵書データ・設定・キャッシュ (%LOCALAPPDATA%\ShelfRow) はアンインストール後も保持します。

コード署名の有無と発行元は、セットアップファイルのプロパティにある「デジタル署名」で確認できます。
未署名版では Windows が発行元を確認できない旨を表示する場合があります。
.sha256 ファイルは配布ファイルの整合性確認用です。
